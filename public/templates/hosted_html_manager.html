API for AI / automation

Use the hostmyapp key to publish from any system.
Single-shot push (creatorName + HTML)
curl -X POST https://YOUR-HOST/api/hosted-html/host \ -H "X-Api-Key: hostmyapp" \ -H "Content-Type: application/json" \ -d '{ "creatorName": "AI Assistant", "title": "Welcome page", "html": "<!doctype html><html>...</html>" }' # Response: { "success": true, "id": "...", "slug": "...", "url": "https://.../h/..." }
Two-step: issue URL first, then upload HTML
# 1) Issue curl -X POST https://YOUR-HOST/api/hosted-html/host/issue \ -H "X-Api-Key: hostmyapp" \ -H "Content-Type: application/json" \ -d '{ "creatorName": "AI Assistant", "title": "My Page" }' # Response: { "id": "42", "slug": "abc...", "url": "https://.../h/abc...", # "upload_url": "https://.../api/hosted-html/host/42/html", "status": "pending" } # 2) Upload HTML to the issued app curl -X PUT https://YOUR-HOST/api/hosted-html/host/42/html \ -H "X-Api-Key: hostmyapp" \ -H "Content-Type: application/json" \ -d '{ "html": "<!doctype html><html>...</html>" }'
Manage what you pushed
# List all apps pushed by hostmyapp curl https://YOUR-HOST/api/hosted-html/host/list -H "X-Api-Key: hostmyapp" # Disable a specific app curl -X POST https://YOUR-HOST/api/hosted-html/host/42/disable -H "X-Api-Key: hostmyapp"

Override the default key in production by setting HOSTED_HTML_API_KEY in your environment.
