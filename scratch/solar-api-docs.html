API docs

Eternalgy — Domestic Solar Calculator API

One API call returns a complete HTML result page for a domestic solar ROI calculation. The same engine as /domestic.

none — public. Optional login cookie is attached when present, for activity logging only.

Quickstart

1. GET https://calculator.atap.solar/api/solar-calculation/docs ← this endpoint

2. Open https://calculator.atap.solar/api/solar-calculation/page?amount=500 in a browser — that is the result page.

3. Minimum body/query is { "amount": 500 }. Defaults match the live /domestic planner, including SuRIA RM 3000.

4. For raw numbers instead of a page, GET https://calculator.atap.solar/api/solar-calculation (no defaults — send every required field) or https://calculator.atap.solar/api/solar-calculation/page?amount=500&format=json.

5. Do not add SuRIA into fixedDiscount yourself when suriaRebate is true — the page API already folds it in.

6. morningUsage is a percent of monthly solar generation, not of household load.

7. Invalid inputs return 400. HTML callers get an HTML error page; JSON callers get { error, details }.

GET /api/solar-calculation/docs

THIS endpoint. Self-describing API docs. Show this URL to an AI agent or open it in a browser.

GET /api/calculate-bill

Match a monthly TNB bill to the closest domestic tariff row. Returns usage_kwh used by the solar calc.

Query

amount number (required) — monthly bill in RM
afaRate number (optional) — historical AFA used only to match the current bill 
curl -G "https://calculator.atap.solar/api/calculate-bill" --data-urlencode "amount=500" --data-urlencode "afaRate=-0.0047"
GET /api/solar-calculation

JSON calculator. Same math as /domestic. Caller must send validated fields; this route does not apply page defaults.

Query

amount number (required)
sunPeakHour 3.0–4.5
morningUsage 1–100 (percent of solar generation used in the morning)
panelType wattage, e.g. 650
smpPrice 0.19–0.2703
afaRate projected AFA for the after-solar bill
historicalAfaRate AFA used to match the current bill
percentDiscount number
fixedDiscount RM, already including SuRIA if the client added it
systemPhase 1 or 3
inverterType string | hybrid
batterySize 0 | 16 | 32 | 48
overridePanels optional integer ≥ 1 
curl -G "https://calculator.atap.solar/api/solar-calculation" --data-urlencode "amount=500" --data-urlencode "sunPeakHour=3.4" --data-urlencode "morningUsage=30" --data-urlencode "panelType=650" --data-urlencode "smpPrice=0.2703" --data-urlencode "afaRate=0" --data-urlencode "historicalAfaRate=-0.0047" --data-urlencode "percentDiscount=0" --data-urlencode "fixedDiscount=3000" --data-urlencode "systemPhase=3" --data-urlencode "inverterType=string" --data-urlencode "batterySize=0"
GET /api/solar-calculation/page

Return a complete HTML result page. Applies live-planner defaults so `amount` alone is enough.

Query

amount number (required) — monthly bill in RM. Also accepts billAmount.
sunPeakHour number, default 3.4
morningUsage percent, default 30
panelType watts, default 650
smpPrice default 0.2703
afaRate projected AFA, default 0
historicalAfaRate bill-match AFA, default -0.0047
percentDiscount default 0
fixedDiscount RM extra discount, default 0
suriaRebate true|false, default true (adds RM 3000 to fixedDiscount)
systemPhase 1 or 3, default 3
inverterType string|hybrid, default string
batterySize 0|16|32|48, default 0
batteryLossPercent 0–20, default 0
batteryDodPercent 0–10, default 5
overridePanels optional integer ≥ 1
cycle fullMonth | under28Days, default fullMonth
format html (default) | json
logActivity set to 0 to skip activity_log 
curl -G "https://calculator.atap.solar/api/solar-calculation/page" --data-urlencode "amount=500"
POST /api/solar-calculation/page

Same as GET page, with a JSON body. Body fields override query string.

JSON body

amount number (required)
sunPeakHour number
morningUsage number
panelType number
batterySize 0 | 16 | 32 | 48
suriaRebate boolean
cycle fullMonth | under28Days
format html | json 
curl -X POST "https://calculator.atap.solar/api/solar-calculation/page" -H "Content-Type: application/json" -d "{\"amount\":500}"
